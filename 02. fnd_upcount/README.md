# 02. fnd_upcount

4자리 7-세그먼트(FND)에 0000부터 9999까지 숫자를 올려 세는 실습입니다.

## 동작

- 전원을 켜면 0000부터 1씩 증가하고, 9999 다음에는 다시 0000
- 숫자 하나를 약 80ms 동안 보여줌 (4자리 × 4ms × 5번 반복)

## 핀 구성

| 구분 | 핀 |
|---|---|
| 자리 선택 D1~D4 | PA5, PB6, PC7, PA10 (LOW일 때 해당 자리 켜짐) |
| 세그먼트 A~G, DP | PA6, PA9, PB5, PB10, PA8, PA7, PB3, PB4 |

## 구현 포인트

### 다이나믹 구동
FND 4자리는 세그먼트 핀(A~G)을 같이 씁니다. 그래서 한 번에 한 자리만 켜고 빠르게 번갈아 보여줍니다.
눈의 잔상 효과 때문에 4자리가 동시에 켜진 것처럼 보입니다.

1. 천의 자리만 켜고 숫자 출력 → 4ms 대기
2. 백의 자리 → 4ms
3. 십의 자리 → 4ms
4. 일의 자리 → 4ms

### 자릿수 분리
```c
one = i % 10;
ten = (i / 10) % 10;
hun = (i / 100) % 10;
tho = (i / 1000) % 10;
```

### 숫자 패턴
`fnd_0()` ~ `fnd_9()` 함수마다 A~G 세그먼트를 켜고 끄는 패턴을 직접 작성했습니다.
