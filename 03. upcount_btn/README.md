# 03. upcount_btn

버튼으로 Run / Stop / Clear를 하는 업카운터입니다.
02번의 FND 코드를 `fnd.c / fnd.h`로 분리하고, 상태 머신과 디바운싱을 적용했습니다.

## 동작

| 버튼 | STOP 상태 | RUN 상태 |
|---|---|---|
| 버튼1 (PC0) | RUN으로 전환 | STOP으로 전환 |
| 버튼2 (PC1) | CLEAR (0으로 초기화 후 STOP) | - |

- RUN 상태에서는 100ms마다 1씩 증가 (0000 ~ 9999)

## 상태 머신

```
        버튼1               버튼1
STOP ─────────▶ RUN ─────────▶ STOP
  │
  │ 버튼2
  ▼
CLEAR ── counter = 0 ──▶ STOP
```

## 구현 포인트

### 비트 시프트 디바운싱
버튼 값을 루프마다(약 1ms) 32비트 변수에 한 칸씩 밀어 넣습니다.
`0xFFFFFFFE` (1이 31번 이어진 뒤 0) 일 때만 "눌림"으로 인식합니다.
버튼이 떨려서(채터링) 0과 1이 섞이면 이 값이 나오지 않아서 무시됩니다.

```c
int edge_detect(uint32_t *btn_val, int new_val)
{
    *btn_val = (*btn_val << 1) | new_val;
    return (*btn_val == 0xFFFFFFFE);
}
```

### FND 드라이버 분리
- 세그먼트 핀을 `{GPIO 포트, 핀}` 구조체 배열로, 숫자 0~9 패턴을 `[10][8]` 배열로 정리
- `fnd_show_number(data)`를 한 번 부를 때마다 한 자리만 표시하고 다음 자리로 넘어감 (static 변수로 현재 자리 기억)

### 블로킹 없는 시간 측정
`HAL_Delay` 대신 `HAL_GetTick()`으로 경과 시간을 비교해서 100ms마다 카운트합니다.
그래서 카운트하는 동안에도 FND 표시와 버튼 입력이 멈추지 않습니다.
