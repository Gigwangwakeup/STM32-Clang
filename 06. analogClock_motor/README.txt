모터 3개를 이용해 시침,분침,초침 을 구현했습니다. 

시계와 스톱워치를 버튼을 이용해 모드 변경이 가능하며, 스톱워치 모드에서 추가적인 2개의 버튼을 이용해 Run/Stop/Clear 을 수행합니다. 
Clear는 Run 도중 초기화를 방기하기 위해 Stop에서만 Clear 가 가능합니다.

## 설계 시 고려사항

### 1. 바늘을 어떻게 빠르게 따라잡게 할 것인가?
시계의 시간은 모드와 상관없이 항상 흐릅니다. 스톱워치에서 시계로 전환했을 때 시계방향으로만 따라잡으면, 목표가 바로 뒤에 있는 경우(예: 59초) 거의 한 바퀴를 돌아야 합니다.

- 구현: 현재 위치와 목표 위치의 차이를 반 바퀴(2048스텝) 기준으로 나누어, 반 바퀴보다 멀면 반시계방향으로 회전하도록 설계했습니다. 이동 거리가 항상 반 바퀴 이하로 줄어듭니다.

### 2. 스텝 오차를 어떻게 보정할 것인가?
모터 1바퀴는 하프스텝 구동 기준 4096스텝으로, 60(초, 분)과 12(시)로 나누어 떨어지지 않습니다. 단위마다 정수 스텝만 더해 가면 소수점 오차가 누적됩니다.

- 구현: 매번 누적 시간 전체를 스텝 위치로 환산했습니다.
  목표 스텝 = 누적 시간 × 4096 ÷ 한 바퀴 시간
  버림 오차가 쌓이지 않아 바늘 위치가 항상 1스텝 이내로 유지됩니다.

### 3. 아날로그 시계다운 움직임
디지털 시간 단위로만 움직이면 바늘이 뚝뚝 끊깁니다.

- 구현: 각 바늘이 한 단계 아래 단위까지 반영하도록 했습니다.
  - 초침: 10ms 단위
  - 분침: 초 단위
  - 시침: 분 단위
