# 08. PWM

버튼 2개로 PWM 신호의 **주파수**와 **듀티비**를 바꾸고, 로직 애널라이저로 파형을 확인한 프로젝트입니다.

## 사용 환경

| 항목 | 내용 |
|---|---|
| 보드 | NUCLEO-F411RE |
| 시스템 클럭 | 100MHz |
| PWM 출력 | TIM1 채널 4 (PA11) |
| 버튼 | PC0 (주파수), PC1 (듀티비) |
| 확인 장비 | 로직 애널라이저 |

## 동작

- **주파수 버튼**: 버튼을 뗄 때마다 100Hz씩 증가
  20Hz → 120Hz → 220Hz → … → 19,920Hz → 다시 20Hz
- **듀티비 버튼**: 버튼을 뗄 때마다 10%씩 증가
  50% → 60% → … → 90% → 0% → 10% → …
- 주파수가 바뀌어도 설정한 듀티비는 그대로 유지

## 원리

### 1. 타이머 클럭 낮추기
PSC = 99 → 100MHz ÷ 100 = **1MHz** (카운터가 1us마다 1씩 증가)

### 2. 주파수 = ARR
카운터가 0부터 ARR까지 세고 0으로 돌아가는 것이 PWM 한 주기입니다.

```
PWM 주파수 = 1MHz / (ARR + 1)
ARR = 1MHz / f - 1
```

### 3. 듀티비 = CCR
PWM 모드 1에서는 카운터가 CCR보다 작은 동안 출력이 High입니다.

```
듀티비 = CCR / (ARR + 1)
```

### 4. 주파수가 바뀌어도 듀티비 유지
ARR만 바꾸면 CCR은 그대로라서 듀티비가 같이 바뀝니다.
그래서 매 루프마다 현재 ARR을 읽어 CCR을 다시 계산합니다.

```c
arr = __HAL_TIM_GET_AUTORELOAD(&htim1);
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_4, arr * incD / 100);
```

### 5. 파형 깨짐 방지
ARR과 CCR의 **프리로드**를 켜 두어서, 새 값이 주기 중간이 아니라 다음 주기가 시작될 때 한꺼번에 적용됩니다.

## 한계

타이머 클럭이 1MHz라서 주기를 1us 단위로만 만들 수 있습니다. 주파수가 높으면 설정값과 실제 값이 조금 달라집니다.
예) 19,920Hz 설정 → 실제 20,000Hz (주기 50us)

## 파일

| 파일 | 역할 |
|---|---|
| `main.c` | PWM 주파수·듀티비 제어 (메인 루프) |
| `driver/button` | 버튼 눌림·뗌 감지 |
| `ap/`, `driver/HCSR04`, `driver/DHT11`, `driver/lcd` | 07번의 거리·온습도 코드를 서비스 구조로 정리한 것 (버튼으로 거리 측정 요청, 결과를 UART로 출력) |

> 현재 `main.c`에서는 `ap_main()` 호출이 주석 처리되어 있어서, PWM 제어만 실행됩니다.
