STM32 버튼으로 PWM 주파수와 듀티비 조절하기 (NUCLEO-F411RE)

버튼 2개로 PWM 신호의 주파수와 듀티비를 바꾸고, 로직 애널라이저로 파형을 확인한 프로젝트입니다.

[사용 환경]
- 보드: NUCLEO-F411RE
- PWM 출력: TIM1 채널 4 (PA11)
- 버튼: PC0 (주파수), PC1 (듀티비)
- 시스템 클럭: 100MHz
- 확인 장비: 로직 애널라이저

[동작]
- 주파수 버튼: 누를 때마다 100Hz씩 증가
  20Hz → 120Hz → 220Hz → ... → 19,920Hz → 다시 20Hz
- 듀티비 버튼: 누를 때마다 10%씩 증가
  시작 50% → 60% → ... → 90% → 0% → 10% → ...
- 주파수가 바뀌어도 설정한 듀티비가 그대로 유지됨

[원리]
1. 타이머 클럭 낮추기
   프리스케일러(PSC)를 99로 설정해서 100MHz를 100으로 나눔
   → 타이머 카운터가 1MHz, 즉 1us마다 1씩 증가

2. 주파수 조절 (ARR)
   카운터가 0부터 ARR까지 세고 다시 0으로 돌아가는 것이 PWM 한 주기
   한 주기는 ARR + 1 클럭이므로
   PWM 주파수 = 1MHz / (ARR + 1)
   → 원하는 주파수 f에 대해 ARR = 1MHz / f - 1

3. 듀티비 조절 (CCR)
   PWM 모드 1에서는 카운터 값이 CCR보다 작은 동안 출력이 High
   듀티비 = CCR / (ARR + 1)

4. 주파수가 바뀌어도 듀티비 유지
   ARR만 바꾸면 CCR은 그대로라서 듀티비가 같이 변함
   그래서 매 루프마다 현재 ARR을 읽어 CCR을 다시 계산함
   CCR = (ARR + 1) × 듀티비(%) / 100

5. 파형 깨짐 방지
   ARR과 CCR의 프리로드를 켜 두어서, 새 값이 주기 중간이 아니라
   다음 주기가 시작될 때 한꺼번에 반영됨

6. 버튼 입력
   메인 루프에서 폴링 방식으로 버튼 상태를 읽음
   {눌렀다 뗄 때 1회 인식 / 디바운싱 방식}

[한계]
타이머 클럭이 1MHz라 주기를 1us 단위로만 만들 수 있음
고주파에서는 설정값과 실제 주파수 사이에 약간의 오차가 생김
예) 19,920Hz 설정 → 실제 20,000Hz (주기 50us)

[결과]
로직 애널라이저로 주파수와 듀티비가 바뀌는 것을 확인했습니다.
